Quick Comp Settings

A native-styled Adobe After Effects CEP extension panel that lets motion designers and video editors inspect and modify composition properties in real time — resolution, framerate, duration timecode, and background color — with instant preview and unified single-step undo.

01 — Features

Speed up repetitive composition edits.

01

Active Comp Auto-Detection

Clicking any composition in the Project panel or timeline instantly populates all five properties into the panel without needing to open the slow modal settings dialog.

02

Unified Single-Step Undo

All changed parameters are batched into a single app.beginUndoGroup call. Pressing Ctrl+Z restores all previous comp settings simultaneously.

03

Strict Timecode Validation

Duration uses AE timecode format (HH:MM:SS:FF). Frame values (FF) are automatically validated against the active framerate to avoid invalid duration errors.

04

Synchronized Color Picker

Click the interactive color swatch to open the native OS color dialog, or type/paste hex codes directly into the #RRGGBB field with real-time two-way synchronization.

05

Native AE Dark Theme

Built with Adobe CEP standards to blend seamlessly into After Effects' default UI, with support for docking anywhere inside your workspace panels.

06

Zero Bloat & Fast Reset

No heavy frameworks or dependencies. A single click of the "Reset" button discards any pending edits and immediately reloads current comp values.

02 — Installation

Quick setup in Adobe After Effects.

1

Windows Automatic Installer

Clone the repository and run the PowerShell script (no admin required). It sets PlayerDebugMode = 1 in HKCU and copies the extension directly into %APPDATA%\Adobe\CEP\extensions\Quick_Comp_Settings\:

.\install.ps1
2

Open Panel in After Effects

Restart Adobe After Effects, then navigate to: Window → Extensions → Quick Comp Settings. Dock the panel anywhere in your workspace.

3

macOS Manual Installation

Copy the panel folder to ~/Library/Application Support/Adobe/CEP/extensions/Quick_Comp_Settings/ and enable debug mode via Terminal:

defaults write com.adobe.CSXS.11 PlayerDebugMode 1
