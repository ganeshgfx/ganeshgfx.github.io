Local AI Logo Remover

A high-performance Windows desktop application that integrates directly into the Windows File Explorer right-click context menu (Windows 10 & Windows 11 modern context menu) to detect and remove AI-generated watermarks from videos and images locally and offline without cloud dependencies.

01 — Features

Local deep learning meets Windows shell.

01

Windows 11 Modern Context Menu

Integrated directly into Windows 11's modern right-click menu using a native C++ COM component implementing IExplorerCommand and packaged via an MSIX Sparse Package.

02

Windows 10 Legacy Integration

Includes automated PowerShell registration scripts (register_win10.ps1) for multi-file right-click execution directly within Windows 10 Explorer.

03

WebGPU Compute Shaders

Custom WGSL compute shader pipeline (webgpuPixelOps.ts) performs hardware-accelerated reverse alpha-blending pixel operations with zero CPU bottlenecks.

04

Bundled AllenK FDnCNN Models

Includes pre-quantized models: model_core_fp32_86x74.onnx (Text watermarks), model_core_fp32_104.onnx (Watermarks ≤ 56px), and model_core_fp32_200.onnx (Default/large).

05

100% Offline & Private

No cloud servers, no subscription APIs, and no telemetry. All video frames are inspected, decoded, processed, and reconstructed strictly inside your local GPU/RAM.

06

Batch Orchestrator & Fallbacks

Queue multiple video files, track progress in real-time, cancel anytime, and fall back to multi-threaded WASM SIMD if a WebGPU-compatible GPU is unavailable.

02 — Architecture

Directory hierarchy & execution flow.

ai-watermark-remover/
├── native/                         # Windows C++ Shell Extension & Manifests
│   ├── CMakeLists.txt              # CMake configuration for shell extension DLL
│   ├── dllmain.cpp                 # DLL entry point & COM ClassFactory
│   ├── GeminiRemoverCommand.h      # IExplorerCommand declaration
│   ├── GeminiRemoverCommand.cpp    # Multi-file collection & app invocation
│   └── registry/
│       ├── register_win10.ps1      # Windows 10 shell integration script
│       └── SparsePackage/          # Windows 11 MSIX Sparse Package manifest
├── resources/
│   ├── models/allenk-fdncnn/       # Bundled ONNX models (104, 200, 86x74)
│   └── onnxruntime/                # Bundled ORT WASM & WebGPU runtimes
└── src/
    ├── engine/
    │   ├── batchOrchestrator.ts    # Sequential batch processing & cancellation
    │   ├── gpuPolicy.ts            # WebGPU & hardware codec capability detection
    │   ├── modelLoader.ts          # Singleton ONNX session cache
    │   ├── onnxBridge.ts           # Bridge to upstream FDnCNN runtime
    │   ├── processingPipeline.ts   # Video inspection, watermark detection & removal
    │   └── webgpuPixelOps.ts       # WGSL compute shader for reverse alpha blending
    ├── main/                       # Electron main process & manifest IPC
    └── renderer/                   # React + Vite processing UI

03 — Installation & Setup

Install AI Watermark Remover on Windows.

A

Method 1: Windows Installer (v1.0.1 Recommended)

Self-contained installer with bundled ONNX models and runtimes (Windows 10/11 64-bit):

Download Setup 1.0.1 (.exe)

SHA-256: B4A0D3F494315F62CB9897F37C3E28E806B7B2F0FD0943229082D6503B6178D2

B

Method 2: Chocolatey Package

Install via Chocolatey package manager in Windows Terminal:

choco install ai-watermark-remover
C

Method 3: Install from Source (Development)

Requires Node.js v18/v20+ and Git:

# 1. Clone repository
git clone https://github.com/ganeshgfx/Local-Ai-Logo-Remover.git
cd Local-Ai-Logo-Remover

# 2. Install dependencies & start dev server
npm install
npm run dev

# 3. Build Windows NSIS installer
npm run build:win
D

Windows 11 Explorer Context Menu (Modern MSIX)

Registers native C++ COM extension into modern Windows 11 right-click menu:

powershell -ExecutionPolicy Bypass -File native\registry\SparsePackage\register_win11.ps1
E

Windows 10 Explorer Context Menu (Legacy Shell)

Registers multi-file context menu handler in Windows 10:

powershell -ExecutionPolicy Bypass -File native\registry\register_win10.ps1

To unregister: powershell -ExecutionPolicy Bypass -File native\registry\unregister_win10.ps1
