GFX Tools

A native Windows desktop application and Adobe Premiere / After Effects CEP panel. Adds a "Paste link" context menu item to Windows File Explorer to download videos from clipboard URLs directly into the active folder with NVENC GPU-accelerated video re-encoding for editors.

01 — Features

Engineered for video professionals.

01

Explorer "Paste link" Menu

Right-click inside any Windows Explorer folder to instantly download video from a clipboard URL (YouTube, Pinterest, Instagram, Vimeo, and 1000+ sites).

02

Shift+Click Advanced Options

Hold Shift while clicking to open an eframe/egui GUI dialog to configure resolution, audio-only / video-only extraction, format bitrate, and trim start/end timestamps.

03

NVENC GPU Acceleration

Hardware-accelerated encoding via NVIDIA NVENC (h264_nvenc and hevc_nvenc), with automatic fallback to CPU (libx264 / libx265).

04

NLE Compatibility Transcoding

Re-encodes downloaded media to standard H.264 + AAC MP4 with non-variable framerates, ensuring zero audio desync or import glitches inside Premiere Pro and DaVinci Resolve.

05

Adobe CEP Plugin Panel

Includes a native CEP extension panel for Premiere Pro and After Effects: paste a URL directly within your editing workspace, download, and auto-import into the project bin.

06

Batch Video Post-Processing

Select multiple video files in Explorer and right-click "Convert to Compatible" or "Compress". All files batch-process concurrently in a unified dark Win32 progress GUI.

03 — Installation

Get GFX Tools on Windows.

A

Windows Package Manager (Winget)

Install via Windows Terminal with automatic updates and PATH registration:

winget install GaneshGFX.GFXTools
B

Chocolatey Package

One-line installation for Chocolatey users:

choco install gfxtools
C

Manual Inno Setup Installer

Download GFXTools_Installer.exe from the GitHub releases page. The installer automatically downloads yt-dlp, FFmpeg, and gallery-dl binaries into your per-user folder (no administrator privileges needed).
